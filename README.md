# 🛒 Retail Growth Analytics Dashboard

 📌 Project Overview

This project presents an end-to-end Retail Analytics solution built using **MySQL, Python, and Power BI**. The objective was to analyze **1 million retail transactions** and uncover insights related to revenue performance, customer behavior, store effectiveness, and promotional campaigns.

The project demonstrates the complete data analytics workflow:

- Data Cleaning & Preparation
- SQL Business Analysis
- KPI Development using DAX
- Interactive Dashboard Design
- Business Insights & Recommendations

---

🎯 Business Problem

Retail organizations generate large volumes of transactional data, but decision-makers often struggle to answer key business questions:

- Which cities generate the highest revenue?
- Which customer segments contribute the most sales?
- Which store formats perform best?
- Do promotions significantly impact revenue?
- How does revenue change over time?

This project addresses these questions through SQL analysis and an interactive Power BI dashboard.

🔍 Key Insights

### Revenue Performance

- Revenue remained stable between **$11.95M and $12.02M** from 2020–2023.
- Revenue variation remained below **1%**.

### Geographic Analysis

- Dallas generated the highest revenue.
- Revenue distribution across cities was highly balanced.

### Customer Analysis

- Teenagers generated the highest revenue.
- Customer revenue contribution remained evenly distributed.
- Average basket value stayed around **$52.4** across all segments.

### Store Performance

- Pharmacy stores generated the highest revenue.
- Revenue contribution across store formats remained balanced.

### Promotion Analysis

- No Promotion generated slightly higher revenue than promotional campaigns.
- BOGO and Discount campaigns delivered similar results.

---

💡 Business Recommendations

1. Maintain geographic diversification.
2. Strengthen customer engagement and loyalty initiatives.
3. Improve basket value through cross-selling and bundling.
4. Continue supporting multiple store formats.
5. Evaluate promotions using profitability and retention metrics rather than revenue alone.
